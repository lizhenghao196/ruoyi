## 系统画像：弹窗切系统后主机列表占位块永不加载（已修）

**现象**：点左上角系统名称 → 弹窗输编号查询后，主机列表首个集群正常；收起再展开、
或展开其他集群，全部停在「滚动到此加载主机明细」。空态输入框查询则完全正常。

**根因**：`doSearch` 里 `loading = true`，模板第 26 行 `v-else-if="loading"` 把整个内容区
换成加载态 ⇒ `hostsPanel` DOM 销毁重建；而 `ensureClusterObserver()` 只判
`if (this._clusterObserver) return`，缓存的观察器 root 已脱离文档，交叉计算恒为 0。

**为何首个集群/空态查询看不出**：首个集群在 `mountedClusters` 里、直接建表不走观察器；
空态时 `searched=false`、panel 未挂载，`ensure` 返回 null 不缓存。

**修复**（`views/tool/systemProfile/index.vue` `ensureClusterObserver`）：
- 判 `_clusterObserverRoot === this.$refs.hostsPanel` 才复用，否则 disconnect + 重建；
- 重建时清掉占位块的 `__spObserved` 标记；
- 回调 unobserve 改用局部 `observer` 变量；
- `beforeDestroy` 里 `_clusterObserverRoot = null`。

**验证**：`Temp/sp_lazy_check.mjs`（Edge headless，路由 `/tool/systemProfile`，admin/admin123）。
A 空态 / B 弹窗 / C 连续切三个场景，各测「收起再展开」「展开第二项并滚到可见」。
回退对照下 B/C 精确复现 `tables:0 placeholders:1`；修复后三个场景全 `tables:1 placeholders:0`。
