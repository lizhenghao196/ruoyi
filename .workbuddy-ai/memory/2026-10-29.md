## 修复：折叠联动在内网失效（是我上一轮引入的回归）

**现象**（用户报）：外网收起单个集群右侧链路跟着变；内网（生产）点了没反应。只有一键收起有效——收起后无图，展开一个则右侧直接全部链路显示。

**根因**：上一轮我自作主张把 `集群关系[组件].nodes` 也并进了 `linkRootNames`。那份数据**不随折叠状态变化**，等于给链路图塞了一组恒定根：
- 收起一个集群 → 关系节点仍覆盖全部 → 图上一条不少（「点了没反应」）
- 一键收起 → `expandedClusters` 空触发守卫 → `[]` → 无图（唯一正常的状态）
- 只展开一个 → 守卫放行 + 关系节点全上 → 全部链路

**证据**：解包 `ruoyi-ui/src/views/tool/systemProfile_20261029.zip`（16:03 打的包 = 内网部署那份），里面的 `linkRootNames` 确实带 `this.relationNodeNames.forEach(...)`。时间线吻合：16:00 我改出 bug → 16:03 用户打包 → 16:42 报障。外网看着正常是因为 mock 里 MYSQL/NGINX 没有集群关系数据；**CANAL/ES/ZOOKEEPER 有，外网也能复现**。

**修复**：
1. `linkRootNames` 只返回 `expandedClusters`；组件拓扑一个集群都没有时才退回 `relationNodeNames`。
2. 关系节点降级为**严格兜底**：只在 `!links.length && allExpanded` 时启用（真·命名口径不一致才救），部分展开时不许兜底。
3. 闭包算完后再剔掉「已收起集群」作为 source 的边 —— 否则 `hfa→bjb` 让收起的 bjb 仍在闭包里，它的出边还留着，还是「点了没反应」。

**验证**：`Temp/sp_toggle_repro.mjs`（复现脚本，A 外网 CANAL / B 外网 MYSQL / C 模拟生产三种场景逐个收起集群）+ `sp_closure_check.mjs` 34 项 + `sp_page_check.mjs` 28 项（新增：收起后该集群出边必须消失、条数必须减少、全收起为 0、口径不一致时全展开才兜底、部分展开不兜底）。

**待办/提醒**：内网要重新打包部署这份修复；`src/views/tool/systemProfile_20261029.zip` 放在 `src` 里会让 webpack 每次编译报 `Module parse failed` 警告（不影响产物），建议挪出 `src`。

## 系统画像：悬浮卡片支持「单击固定 + 复制」

**需求**：卡片一动就消失，内容复制不了；或让节点下面的字也能选中复制（不影响拖拽）。

**结论**：节点名是 echarts canvas 的 scatter label，**物理上无法选中**，只能把可复制做在卡片上。

**实现**（`index.vue`）：
- 单击节点/连线 → `topoHover.pinned = true`，卡片冻结不跟随；文字可划选，右上角出现「复制」「关闭」两个小按钮。
- 取消：再点同一目标 / 点画布空白 / Esc / × / 切组件 / 折叠 / 缩放平移。
- `updateTopoHover` 开头遇 `pinned` 直接 return（这是原来不能复制的根因）。
- `clearTopoHover(mode, force)` 加 `force`：非强制不动固定态；`disposeTopoChart` / `renderTopoChart` / 滚轮缩放 / `onTopoDialogClose` / `resetTopoView` / `openTopoDialog` 传 true。
- `pointer-events` 两态：跟随态 `none`（保住命中测试），`.is-pinned` 才 `auto` + `user-select: text`。
- 单击/拖拽判定：新增 `down = {hit,x,y,moved}`，移动 >4px 算拖拽并顺手 `unpinTopoHover()`；`mouseup` 时 `!moved` 才算单击；`globalout` 不算单击。
- 卡片底部恒有一行提示（跟随/固定两态各一句），高度不变 → 固定瞬间不跳位；`placeTopoHover` 的 rows +1。
- 复制：优先 `navigator.clipboard`，**必须有 `execCommand` 兜底**（内网 http 非安全上下文没有 clipboard API）。

**验证**：`Temp/sp_pin_check.mjs` 38 项（固定/取消/空白/Esc/连线 desc/复制文本拼装/源码断言），既有 `sp_page_check.mjs` 28 项 + `sp_closure_check.mjs` 34 项无回归；dev server 编译通过（仅 zip 那条老警告）。
