改动：
- `linkTopology.js` 新增纯函数 `filterLinksByClusters(links, clusterNames)`：起点名包含任一集群名即命中；
  集群名空数组 -> 返回空数组（**不退回全量**）。
- `index.vue`：`data.allLinks`（全量，给顶部概览）+ `links`（筛选结果）；新增 computed `activeClusters`
  / `linkEmptyTitle` / `linkEmptyHint`；`refreshTopo()`（筛选 + 建拓扑）、`applyComponentLinks()`
  （重筛 + $nextTick 重画两个画布）、`disposeTopoChart(mode)`；`doSearch` 里**先定 activeComponent 再
  prepareData**（顺序反了会按上一次的组件建一遍拓扑）；`selectComponent` 里 `changed` 才重算。
- 空态文案分两种：整份画像没链路 -> 「暂无链路数据」；有链路但该组件没匹配到 -> 「无链路」。
- mock `链路` 整块重写（49 条）：fnode 一律 `<集群名>@<角色>`，每个组件只列自己发出的链路，
  **「测试」组件故意一条都没配**用来验证空态。

⚠️ **echarts 4.9 的 lines 系列根本不渲染 label**（`LinesView` 走 LineDraw/EffectLine，整条链路没有
label 分支），所以线段上的 desc 文字只能用 **scatter** 挂在线段中点（二次贝塞尔 t=0.5）。
两个必须记住的：
- **`symbol: 'none'` 不行**：`SymbolDraw.symbolNeedsDraw` 里有一句
  `data.getItemVisual(idx,'symbol') !== 'none'` —— 为 none 时**元素压根不创建**，label 自然不渲染。
  要用 `symbol: 'circle'` + `itemStyle.color: 'transparent'`。
- **`symbolSize` 必须是 2**：Symbol 内部把图形建成 2×2 再按 `symbolSize/2` 缩放，而 label 就挂在
  这个被缩放的元素上 —— symbolSize=2 时缩放比正好 1，文字才是 fontSize 的真实大小。

直出判据（`topoEdgeLabelOn`）：节点 ≤14 且线段 ≤12 **且**每条带 desc 的线段都放得下自己的文字
（`字数 × 11 + 24 ≤ 两端直线距离`）才直出；有一条不满足就**全部退回悬浮卡片**（避免半张图有字半张没有）。
拖拽节点时 `writeTopoNodePos` 要按 `edgeLabelIndex` 找回标签项重算中点位置。

校验：`sp_verify.mjs`（纯函数 + mock 对应关系 + 抠页面脚本跑集成 + SCSS + 源码防回归，FAILURES 0）、
`sp_shot.mjs`（playwright + 本机 Chrome，含**开/关标签 A/B 像素对照**：有墨像素 469 vs 10，
证明文字真的画出来了，FAILURES 0）。截图在 `Temp/sp_shots/`。

⚠️ 像素校验踩的坑：用「精确 hex 匹配文字色」会**假红** —— 10.5px 的 CJK 笔画只有 1px 宽，

## 系统画像补充 2：desc 文字过多 + 文字贴着线条（用户追加要求）

用户原话：「你要考虑 desc 文字过多时的显示效果，还有，这个文字可以贴着线条展示吗」。

**① 文字顺着线段转 + 贴着线不压线**
- 新增 `lineAngle(a, b)`：二次贝塞尔在 t=0.5 的切线**平行于两端连线**（P2−P0），
  所以直接用弦的方向，不用求导；角度归一到 `(-90, 90]`（朝左的线翻 180°，否则文字是倒的）。
- 新增 `edgeLabelAnchor(a, b, curveness)`：锚点 = 曲线中点沿法线让开 `TOPO_EDGE_LABEL_OFFSET`(11)px。
  「贴着线」但不盖住线；想让文字压在线上把 OFFSET 设 0 即可。
- 角度**逐条**挂在数据项上 `label: { rotate }`（每条线角度不同，不能写在系列上）。
- ⚠️ echarts 会把 `rotate` 转成**弧度**存进 `style.textRotation`；拖拽时要**整颗替换**数据项
  （`state.edgeLabelItems[li] = {...}`）而不是原地改 `label.rotate` —— 原地改不保证被重读。
  能刷新的原因：`SymbolDraw.updateData` 的 update 分支会 `symbolPath.setStyle(...)` 标记脏，
  且同层节点在动画，整层会重绘。

**② desc 文字过多：按线段实际宽度自适应截断**
- 新增 `charWidth` / `estimateTextWidth` / `fitText`：**逐字累加**估宽（中日韩/全角 11px、其余 6.2px）。
  ⚠️ 早期用「字数 × 11」，中英混排会忽长忽短 —— `sp_verify` 有防回归断言。
- `预算 = min(线段长 − PAD(26), MAX_W(200))`；不足 `MIN_W(60)` 才整体不画。
  ⇒ 长线多画几个字、短线少画几个字，**不再**因为「desc 太长」整块放弃。全文在悬浮卡片里。
- `topoEdgeLabelOn`（布尔）重构成 `edgeLabelPlans`（返回排版计划或 null），
  多了一层**碰撞判定**：文字块按旋转后的四边形做**分离轴定理**（`quadsOverlap`），
  四周再外扩 `GAP(6)` 留呼吸空间，任意两块压一起就整体退回悬浮卡片。
- mock 里把 bjc 那条 NGINX 的 desc 故意写长（「南方机房入口负载均衡，与北京节点互为主备」）
  用来演示截断效果。

校验：`sp_verify.mjs` FAILURES 0（新增 `lineAngle` 八个方向、`edgeLabelAnchor` 法线偏移、
`quadsOverlap` 分离轴 6 组、自适应截断宽度不超预算、上限 200px 卡住、中英混排、
