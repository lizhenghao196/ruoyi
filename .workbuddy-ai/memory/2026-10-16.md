## 启动前后端（Redis + 后端 + 前端）

按约定顺序启动三件套，最终全部就绪：Redis `127.0.0.1:6379`、后端 `:8080`（Started in 14.8s）、前端 `:80`（代理 8080 返回 200）。

⚠️ **踩坑：`&` 不能和后台任务一起用**。第一次用 `cmd ... > log 2>&1 &` 配合后台运行，包装 shell 立即退出，**子进程（redis-server / java / npm）随即被回收**：
- Redis 被回收 → 后端启动时 `RedisConnectionFailureException: Connection refused 127.0.0.1:6379` → `sysConfigServiceImpl` 初始化失败 → 整个 Spring 上下文启动失败（表面症状是「后端日志停在 druid profile 就不动了」）。
- 排查要点：`tasklist | grep -i java` 发现 java 进程消失 = 被回收，不是启动慢。

**正确姿势**：直接跑命令（**不带 `&`**），把整条命令交给后台任务机制常驻，需要日志就 `> xxx.log 2>&1`（重定向可以有，`&` 不能有）。本次后台任务 id：Redis=`CylD2i`、后端=`cN7aIg`、前端=`WkX7of`。

## 工单甘特图：横坐标固定为「当天 18:00 → 次日 06:00」

用户要求把甘特图横坐标**固定住**（原来是按数据自适应，跨度能到 27 小时、柱子被压得很窄），
「当天」跟着页面日期选择器走，**日期不许写死**。

改动四处（纯前端）：
- `ganttLayout.js`：新增 `WINDOW_START_HOUR=18` / `WINDOW_END_HOUR=30` + 纯函数 `buildDayWindow(date)`
  （当天 00:00 + 18h / + 30h，写成 30 点省掉跨天判断）；`measureTimeAxis(items, maxTicks, timeWindow)`
  新增第三参，`buildLayout` 走 `options.window` 透传 —— **不传就退回自适应**（组件可独立使用）。
- `OrderGantt.vue`：新增 prop `windowDate` + computed `timeWindow`，传给 `measureTimeAxis` / `buildLayout`。
- `index.vue`：`<order-gantt :window-date="date" />`。
- `api/tool/orderGantt.js`：mock 样例的时间写成**占位日期**（`2026-09-17`=当天 / `2026-09-18`=次日），
  返回前用 `shiftMockDates(data, params.date)` 单次正则替换成真实日期。另把 0110/0111/0205
  三条原本在窗口外的样例（09:00 / 13:00 / 10:00 开始）挪进 18:00~06:00 窗口内。

⚠️ **踩到的坑（原代码潜伏 bug，固定窗口后才可达）**：`buildLayout` 的裁剪分支
`if (left < 0) { width += left }` 没夹下限 —— 窗口外的工单会算出**负宽度**（CSS 当无效声明忽略，
柱子反而按内容撑开），且 `left > plotWidth` 时会把 `overflow-x: auto` 的容器撑出横向滚动条。
改成 `width = Math.max(0, width + left)` + `left > plotWidth` 时归零，并在组件里加
`visibleBars`（过滤 `width > 0`）—— 窗口外工单仍计入 `stats.total`，但不渲染。

效果：绘图区固定 12 小时 → 每格 60 分钟共 13 个刻度、日期带 2 段（当天/次日），
柱体文字从 **2/8 条** 涨到 **6/8 条**（柱子变宽，不再被压成细线）。

校验：新增 `og_window_check.mjs`（纯函数 + mock 端到端 + 源码接线，FAILURES 0）、
`og_probe_window_live.mjs`（真实浏览器：刻度序列 / 日期带 / 柱子像素反算时间 / 不滚动，FAILURES 0）；
复跑 `og_verify.mjs`（281 通过 + 6 条 EBUSY 假红，与改动前一致）、`og_syntax_check.mjs`（0）、
`og_check_labels.mjs`（0）、`og_filter_check.mjs`（0）、`og_rows.mjs`（可下挪 0 条）。
