## 工单甘特图：气泡进度条第 2 色（粉/玫红）换成蓝色

**用户**：「表格里面占比进度条…第二个颜色好像是红色告警色，不要这个颜色，换一种颜色」

**定位**：气泡明细表占比进度条的调色板 `BAR_PALETTE`（`components/OrderGantt.vue`），
第 2 色（index 1）是粉 `#fbd8e3` 填充 + `#f090b1` 描边 —— 玫红系，观感撞上本系统里
「红色 = 告警」的语义。真实页面上 detail 是 3 行（30/15/5），所以绿→**粉**→黄，
第 2 行就是那个粉条。

**改动**（只动 `components/OrderGantt.vue` 一个文件）：
- `BAR_PALETTE` 第 2 项 `{ fill: '#fbd8e3', line: '#f090b1' } // 粉`
  → `{ fill: '#d6e6ff', line: '#7ba7f5' } // 蓝`。
  现在 6 色 = **绿 蓝 黄 橙 青 紫**（色相 146/218/45/28/182/248°），全在安全区。
- 顺手修正上方注释里一个不实数字：原文写「深字 on 这几个填充的对比度都在 **12:1** 以上」，
  实测最差是 **10.64**（紫 `#dcd8f8`），改为「最差 10.6:1」。
- 注释里补上「**避开红 / 玫红 / 粉**」这条约束与本次变更记录。

**为什么选蓝**：调色板里绿/黄/橙/青/紫都已占用，唯一「明确不像告警、且与现有色相区分」
的冷色就是蓝；`#d6e6ff` 的填充对深字 `#1f2937` 对比度 11.6:1，与其它行同量级。
（与 MANUAL 组的语义蓝 `#5b9cf8` 同族，但气泡条是纯装饰、且比它浅一档，实际不混。）

**防回归**：`og_syntax_check.mjs` 新增第 6 段断言 —— 按**色相**判，`<=20°`（红）
或 `>=320°`（玫红/粉）即失败，填充与描边都查；并把每色的色相打印出来。以后换色会被它挡住。

**校验**（全绿）：
- `og_syntax_check.mjs`：语法 + 对比度 10.64 + 调色板无红粉。`FAILURES: 0`
- `og_shot_tipbar.mjs`（两份静态预览）：行色变成 `rgb(200,240,217) rgb(214,230,255) rgb(253,238,194)`，
  宽度比 / 气泡高度不变。`FAILURES: 0`
- `og_probe_tipbar_live.mjs`（真实页面）：悬浮 AUTO 矩形 → 绿 100% / **蓝 50%** / 黄 16.67%。`FAILURES: 0`
- 回归：`og_scss` / `og_verify_browser` / `og_verify_tip` 均 `FAILURES: 0`；
  `og_rows` 可往下挪 0 条；`og_diag` 间隙 >= 0；`og_ink_check` 柱体文字对比度未变。
