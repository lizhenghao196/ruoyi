### 踩到的坑（都写进 REF 了）

1. **可用高度必须扣掉标签条**：`fitRowPlan` 反推行高时漏扣，整图会正好多出 22px，底部被 `overflow-y: hidden` 裁掉。解法是让 `fitRowPlan` 和 `buildLayout` **共用** `groupStripHeights()`。
2. **静态预览页一直「看起来有问题」的真因**（这次才挖出来）：`og_preview*.mjs` 生成的 HTML 里 `.og` 的 `<div>` **没闭合**，后面的 `.stage`（气泡示例）成了 `.og` 的 flex 子项，把 `.og__plotwrap` 挤到只剩 ~190px，柱体全被裁 —— 之前 09-22 的笔记把它记成「预览脚本的 DIALOG_VH 偏小」，其实是闭合错误。
3. 预览页另外两处失真的地方也一并修了：`.shell` 宽度 1320 → 1322（让 plotwrap 的 clientWidth 正好 = plotWidth，否则凭空多 2px 横向滚动）、竖向网格线/轴短线要按组件的 `gridTicks` 过滤（`x < plotWidth - 0.5`）。
4. 断言别直接 grep 源码里的中文：**注释里会提到被删掉的旧叫法**（「占用行数」「手动 / 其他」），要先 `stripComments` 再判，否则永远假红。
5. **`textWidth()` 里缓存查在「取量具」之前 —— 自己写出来又自己抓到的 bug**：字体族要挂载后才解析得出来，
   量具检测到字体变化会清缓存；缓存先命中的话首帧用兜底字体量出的宽度会被永久复用。
   已改成「先取量具再查缓存」，并给字体串加 `_labelFontReady` 只解析一次
   （每次渲染会调上百次 `getComputedStyle`，扛不住）。两条都写成了 `og_verify.mjs` §5.6 的源码级回归断言。
