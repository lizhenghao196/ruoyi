# 2026-11-09

## 系统画像：组件配套操作（三个按钮 + 两个弹窗）

需求：组件拓扑选中 NGINX / HAPROXY / 微服务 / JAVA微服务 时，主机列表每个集群的折叠头中间放三个按钮；
点按钮不能触发折叠/展开；记录数移到最右、紧贴 Element 自带展开箭头。

### 改动
- `ruoyi-ui/src/utils/request.js`：成功码白名单 `SUCCESS_CODES = [200, '200', '0000']`，
  分支改成 `SUCCESS_CODES.indexOf(code) < 0`。配置中心系列接口成功码是**字符串 '0000'**。
- `ruoyi-ui/src/api/tool/systemProfile.js`：新增 `downloadConfigToLocal` / `readComponentConfig` / `readComponentLink`，
  url 分别 `/proxy/profile_center/download/config`、`/readconfig`、`/config/readLink`，都是 post。
  文件顶部 `USE_MOCK = true`（含 3 份 mock，content 刻意带 \n \t），接真实后端改 false。
- `ruoyi-ui/src/views/tool/systemProfile/index.vue`：
  - 折叠头改成三列 grid（`__head` / `__lead` / `__actions` / `__count`），中间列 auto ⇒ 按钮恒居中；
    按钮容器和按钮都 `@click.stop`（容器绑 `blockBubble`，空函数）才不连带折叠。
  - 新增两个弹窗：组件配套文件（el-tabs，一个文件一个 tab，内容 `<pre>` + `white-space: pre` + `tab-size: 4`，
    底部固定 msg）、链路信息（vue-json-viewer `:expand-depth="2"` + 框内滚动 + 复制 JSON）。
  - loading 用 `cfgLoading` 对象，key = `集群名|动作`，必须 `$set`/`$delete`（Vue 2 新 key 不响应）。
  - `copyTopoHover` 里的复制逻辑抽成 `copyPlainText`，JSON 复制复用。
  - `systemId` computed：`基础信息.systemId || 基础信息.系统编码 || systemQuery`。

### 校验
- `Temp/sp_cfg_verify.mjs`（node，87 条）：SFC 模板/脚本、SCSS 产物（grid 三列、pre、tab-size）、
  request 白名单、api url/method、页面实例行为（loading 锁、三个 handler、参数、复制 JSON）。
- `Temp/sp_cfg_shot.mjs`（playwright+msedge）：折叠头几何（按钮居中偏差 0px、记录数贴箭头、不重叠）、
  点按钮不折叠、两个弹窗内容（36 行原文保留、tab 切换、jv 默认 2 层）、下载 loading + 提示原文、
  MYSQL 下按钮消失。全绿。
- `Temp/sp_cfg_narrow.mjs`：1280 宽下 HAPROXY 四个长名集群仍单行不挤。

### 踩点
- `.profile-cluster` 只是 BEM 前缀，**没有**同名元素，选择器要用 `.profile-cluster__head`。
- `el-tabs` 的 nav 第一个子节点是 `.el-tabs__active-bar`，`nth-child(2)` 命中的是**第一个 tab**。
- vue-json-viewer 的 DOM 类名是 `.jv-node` / `.jv-key-node` / `.jv-toggle.open` / `.jv-ellipsis`，没有 `.jv-row`。
