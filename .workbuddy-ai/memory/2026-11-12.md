## 系统画像：刷新改成整页 loading 遮罩（用户追加要求）
- 用户要「点刷新 → 重新请求 → 页面加 loading」，所以在 `.profile-page` 根节点挂 `v-loading="refreshing"` + `element-loading-text="正在刷新系统画像..."` + `element-loading-background="rgba(245,247,250,0.72)"`。
- 仍然**不能**绑 `loading`（那会把内容区换成加载态，刷新按钮自己消失），所以 `refreshing` 与 `loading` 保持两个独立标志；遮罩期间内容还在，刷新完原地换数据。
- 实测（`Temp/profile_loading.mjs` / `profile_loading2.mjs` / `probe_center.mjs`）：mask 尺寸 = 1400x866 与 `.profile-page` 完全一致、spinner 水平垂直居中（`width:100%` + `text-align:center`）、关闭后 mask 留在 DOM 但 `display:none` 且 `elementFromPoint` 命中的是真实内容（不挡点击）、二次点击能复用实例重新显示。
