## 修正：并行组在 relations 里是「一条直线」（用户指出）

### 用户指出的问题
我原来造的 relations 是**菱形分叉**（A→B、A→C、B→D、C→D），画出来并行组周围有扇出/扇入，一个节点会有 3 条线。
**真实数据不是这样**：并行组在 relations 里仍然是**一条直线** `A → B → C → D → E`（B、C 同组），
任何节点的入度、出度都**不会超过 1**；并行关系只体现在 `aniNodeGroup` 上，不体现在连线上。

### 改造一：把 mock 数据线性化（`mockData/res.js`）
- 脚本 `C:/Users/lenovo/AppData/Local/Temp/fix_relations.mjs`：对每条流做 Kahn 拓扑 + 最长路径分层，
  再按 `(层, 原数组下标)` 排序得到**合法拓扑序**（并行组成员天然相邻），然后把相邻两两连成一条直线。
- 只改 `relations` 数组，`nodes` 一个字节没动；`anirInstanceRelationId` 复用原有的（新关系数 = n-1 ≤ 原关系数，够用）。
- 用确定性 PRNG（mulberry32，seed = `awiWorkflowInstanceId`）打乱数组顺序，**保留真实数据「乱序」的特征**。
- 文本级替换：正则定位 `\n( *)relations: \[` → 括号配对找结尾 → 往前找最近的 `awiWorkflowInstanceId` 判定所属流
  → 从后往前替换（避免偏移失效）。**注意替换文本结尾不要带逗号**，原 `]` 后面的 `,` 会保留，否则出现 `],,`。
- 备份 `mockData/res4.js.bak`（= 线性化之前的版本）。
- 结果：**21 条流 / 207 节点 / 187 条关系**（每条非空流都是 n-1 条），入度出度全部 ≤ 1，直线覆盖全部节点，53 个并行组成员在直线上相邻。

### 改造二：布局引擎改成「先收缩并行组」（`flowLayout.js`）
- 只做拓扑分层**不行**了：直线里 B→C 是真实边，会把 B、C 排到相邻两列，看不出「并行」。

## 执行页面改造为「轮询」模式（用户提出）

### 需求
「这个页面是轮询的……每个流每个节点是有状态的……你先把页面搞成轮询的，**但是轮询的时候不能影响用户操作**。」

### 关键设计：静默轮询 + DOM 复用
轮询最大的风险是打断用户（滚动位置丢失、卡片重建、页面闪 loading）。逐条对策：

- **`loading` 与 `refreshing` 分开**：`loading` 只在首屏/换参时用（会切 `v-if` 分支、重建 DOM）；轮询走 `refreshing`，**不切分支、不遮页面**，只换 `results` 数据。
- **流的 key 稳定**：`flow.key = ${planId}-${awiWorkflowInstanceId}`，与状态无关。Vue 复用同一批 DOM 节点 → 滚动位置、`:hover` 状态天然保留。
- **布局几何与状态解耦**：`layoutFlow` 只依赖 `nodes`/`relations` 的**结构**，不依赖 `aniStatus`。所以状态变化时坐标逐字节不变，画面不跳。这条已用断言硬性验证（首轮 vs 末轮几何签名完全一致）。
- **`.exec-page__body { overflow-anchor: none }`**：关掉浏览器的滚动锚定，内容更新时滚动位置完全由用户控制，不会被浏览器"自动修正"。
- **页面隐藏即停**：`visibilitychange` → hidden 时 `stopPolling()`，visible 时先补拉一次再恢复计时。
- **防请求堆叠**：静默轮询时若上一次还没回来（`refreshing === true`）直接跳过本轮；另用 `reqSeq` 递增序号丢弃过期响应（last-write-wins）。
- **单点失败不清空**：某个 planId 拉失败时**沿用上一次的数据**（标 `stale`），避免页面局部塌陷；`failedIds` 非空时状态条变红显示「部分失败」。
- 页面切后台/回来、手动刷新按钮都**不重置轮询计时**（`refreshNow` 只是额外拉一次）。

### 状态变化的可见性：蓝色脉冲
- `FlowGraph.vue` 内部 `watch: graph`，对比前后两次的 `nodes[].node.aniStatus`，变化的节点 id 进 `flashed` 集合，加 `.is-flash`。
- 动画用 **`box-shadow` 脉冲**（`flow-flash` 1.6s × 2），**不碰尺寸**，所以不会推动任何东西。`FLASH_MS = 3200` 与动画总时长对齐。
